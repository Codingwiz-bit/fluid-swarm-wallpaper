A high-performance, GPU-accelerated interactive canvas wallpaper designed specifically for macOS external monitors and the [Plash](https://github.com/sindresorhus/plash) desktop webview engine.

## 🚀 How to Use on macOS

### Step 1: Install Plash
Download and install [Plash](https://github.com/sindresorhus/plash) (Free & Open Source on the Mac App Store).

### Step 2: Add the Wallpaper
1. Click the **Plash** icon in your macOS menu bar.
2. Select **"Add Website..."** → Click **"Open File..."**.
3. Choose `Fluid Swarm V4/index.html` from this repository.
4. Set the display to your external monitor.

### Step 3: Enable Mouse Interaction (Optional)
- In Plash's preferences/menu, check **"Interact with website" / "Browsing Mode"** if you want the particles to react to your mouse movements, clicks, and double-clicks!

## ⌨️ Controls

- **Mouse Move:** Repels particles and stirs fluid flow.
- **Right-Click:** Cycles through the 4 physics modes.
- **Double-Click:** Triggers a cinematic shockwave blast.
- **Mouse Idle (3+ seconds):** Automatically morphs into geometric screensaver mode, Particle Clock, and symbols.
